# tarot-three

> A 3D Tarot Card Visualization Project built with Three.js

## 项目状态

**当前版本**: v0.1.0 (开发中)

这是一个学习 Three.js 过程中的练手项目，探索3D卡牌可视化的实现方式。

## 功能列表

### 已完成
- [x] 3D卡牌渲染
- [x] 卡牌翻转动画
- [x] 牌阵布局算法
- [x] 用户登录表单

### 进行中
- [ ] 卡牌3D旋转交互
- [ ] 牌义解读功能
- [ ] 用户交互优化

### 计划中
- [ ] AI塔罗师对话功能
- [ ] 更多牌阵样式

## 技术栈

- **Three.js** - 3D渲染
- **Vanilla JavaScript** - 核心逻辑
- **HTML/CSS** - 前端界面

## 运行项目

```bash
# 安装依赖
npm install

# 本地开发（如有开发服务器）
npm run dev

# 或直接打开 index.html 查看
```

## 项目结构

```
tarot-three/
├── index.html          # 主页面
├── full_flow_v4.html   # 完整流程测试页
├── src/                # 源代码
├── public/             # 静态资源
└── dist/               # 构建输出
```
